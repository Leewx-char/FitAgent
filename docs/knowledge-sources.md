# 中文外部知识源

本项目将外部资料分为两类：可再利用的数据集，以及只供审核的权威资料。所有原始文件都放在 `storage/rag/sources/`，该目录已被 Git 忽略；离线索引器只读取 `data/`，因此暂存资料不会被意外写入 Qdrant。

FitKG-CN 的发布记录为 CC BY 4.0，包含 11,544 条中文语句、26,494 个实体及 15,455 条关系。它已被转换为 `data/external/fitkg-cn/` 下的训练集和验证集 Markdown 文档；每个样本使用二级标题分隔，并保留实体、关系、出处和许可说明。索引器对 Markdown 先使用 `MarkdownHeaderTextSplitter` 按一级、二级标题切分，再使用递归分割器将过长片段控制到配置长度。

## 进入正式知识库的门禁

1. 在 `config/knowledge_sources.yml` 登记来源、版本、许可、下载哈希与适用范围。
2. 审核许可；未声明可再利用许可的网页和指南只能保留在审核区。
3. 对候选内容做去重、领域专家抽检、风险提示和引用保留。
4. 通过后生成小型、可审计的 `.txt` 或 `.pdf` 文件至 `data/`，再运行 `python -m app.services.knowledge_indexer` 创建新索引版本。

这条路径保留了演示所需的生产演进边界：来源可追溯、数据与在线服务解耦，且不把健康建议未经审核地暴露给用户。

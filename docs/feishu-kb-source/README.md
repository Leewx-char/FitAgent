# FitAgent 飞书知识库源稿

此目录保存同步到飞书知识库的核心导读源稿，便于后续随代码变更复核和重建。源稿以 `README.md`、`docs/architecture.md`、`docs/api-contract.md` 和 `docs/learning-guide.md` 为当前口径；`docs/refactoring/` 只作为演进背景，不作为现状的唯一依据。

- `00-项目总览与知识库导航.xml`：全局地图、导航、第一条聊天链路。
- `01-后端文件与函数索引.xml`：后端模块、类、函数和测试入口。
- `02-前端文件与函数索引.xml`：Vue 页面、状态、API 与 SSE 渲染。
- `03-核心技术链路.xml`：RAG、Agent、记忆、计划和 Coros 的设计/数据流。
- `04-端到端阅读路线.xml`：按用户动作组织的阅读路线和验证方式。
- `05-原始学习资料说明.xml`：本地原始学习资料与阅读优先级说明。

原始学习资料仍保留于 `docs/`，并会作为飞书知识库中的“原始学习资料”迁入。

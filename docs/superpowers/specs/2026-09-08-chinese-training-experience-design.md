# 中文训练经验等级契约

## 目标

使训练计划安全策略使用前端当前提交的中文训练经验值：`新手`、`中级`、`高级`。不再以英文经验值作为强度判断条件。

## 范围

- 保持前端引导页和资料页的三个既有选项不变。
- 后端将画像经验值的默认值和说明统一为中文。
- 安全策略以 `高级` 作为初始最高强度为“高”的唯一条件；`新手`与`中级`的初始最高强度均为“中”。
- 既有伤病、负荷、睡眠、疲劳、疼痛与 RPE 降级规则保持不变。

不包含训练天数或训练时长的按等级推荐，也不添加英文值兼容或数据迁移。

## 数据流

前端保存 `新手 / 中级 / 高级` 到用户画像。训练计划生成时，`TrainingSafetyPolicy` 读取该值，先计算基础强度上限，再应用近期恢复风险的降级规则。最终计划仍须通过服务端动作强度校验后才能持久化。

## 验证

- `高级` 且不存在风险信号时，初始强度上限为“高”。
- `新手`或`中级`且不存在风险信号时，初始强度上限为“中”。
- 任一既有风险信号仍可将任意等级降至“低”。
- 训练计划 API 与现有前端提交的中文值保持可用。

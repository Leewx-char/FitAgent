# FitAgent 简历写法

> 只写能结合源码讲清楚的内容；不要写“医学诊断”“多 Agent”“自动下发训练计划”或“官方 Coros OAuth 已生产化”。

**FitAgent — 可解释 RAG 私人健身 Agent** · **项目角色：LLM 应用开发 / 全栈开发**

**技术栈：Python、FastAPI、LangChain/LangGraph、DashScope、Qdrant、BM25、MySQL、Vue 3、ECharts、MCP**

面向个人健身场景开发的 LLM 应用，整合训练知识、用户画像和 Coros 运动数据，帮助用户获得有依据的训练建议与周计划。

**核心工作**

1. **可解释 RAG**：使用向量检索和关键词检索获取健身知识，并向用户展示真实的来源和证据卡片，减少“模型凭空给建议”的问题。
2. **用户受控记忆**：用户在聊天中提到的目标、伤病和偏好，先作为候选记忆；只有用户确认后，系统才会在后续对话中使用，并支持撤销和过期。
3. **自适应训练计划**：结合用户画像、近四周 Coros 运动数据和训练反馈生成周计划；后端会检查训练天数、动作强度和证据来源，避免模型直接输出不合理计划。

术语说明：DashScope 是阿里云百炼的模型服务；ECharts 用于展示训练负荷、HRV 和睡眠等运动数据图表。
